# SEO audit — September 13, 2026

## Findings

Fresh Search Console snapshot, September 4–10: 1 click, 245 impressions, 0.41% CTR, average position 58.95. August 9–15 recorded 59 clicks and 3,472 impressions. These are equal-length windows but the earlier one is a historical benchmark, not a controlled comparison. The latest window predates the September 11–12 recovery edits; it cannot measure their effect. Recent snapshot windows overlap, so their deltas are not independent weekly comparisons.

Live GET crawl of all 87 sitemap URLs: all returned HTTP 200, with one self-referencing canonical, one H1, a description and no noindex directive. No duplicate titles or descriptions among these URLs. The apex homepage redirects to the www homepage. robots.txt and sitemap.xml return 200. Raw results: `technical-crawl-2026-09-13.json`.

These checks do not establish Google's actual indexing status, selected canonicals, Core Web Vitals, or the cause of the traffic decline. Previous manual-action/security checks are recorded as September 11 observations, not rechecked today.

## Local changes

- Removed WebSite SearchAction markup: the target ranking page has no search implementation.
- Added visible breadcrumbs and matching BreadcrumbList JSON-LD to 19 guides and 5 news articles.
- Added article Open Graph metadata to guides and explicit article URLs to news metadata.
- Added NewsArticle markup using existing headlines, publication dates, publisher and source URLs. No new authors, review dates or factual claims were invented. This does not constitute a source audit of news content.
- Replaced stale “420+ verified Trustpilot reviews” wording in news CTAs with a link description reflecting the review's dated evidence and verification limits.

No deployment performed in this session. Canonicals, indexing directives and existing URLs are unchanged.

## Next priorities

1. Obtain actual publisher/legal ownership, shared ownership with featured firms, compensation relationships and responsible author/reviewer identities. Existing independence and no-compensation assertions remain unverified; do not invent replacements.
2. Complete source audits for the remaining nine firm reviews and substantiate category scores. Eight source updates are documented across September 11–12; source updates alone do not validate scores.
3. Audit news, guide and industry-page claims, particularly financial/legal conclusions, company endorsements and assertions of original research. Structured-data correctness does not establish factual quality.
4. Compare complete, non-overlapping post-publication periods, then a full 28-day period. Use URL Inspection for representative core pages before considering URL consolidation. Existing query overlap is not proof that consolidation would reverse the decline.

Google's [review guidance](https://developers.google.com/search/docs/specialty/ecommerce/write-high-quality-reviews) emphasizes supporting evidence and useful comparisons. Its [structured-data policies](https://developers.google.com/search/docs/appearance/structured-data/sd-policies) require representative, non-misleading markup. These support the cleanup priorities but do not diagnose this site's ranking decline or guarantee recovery.
